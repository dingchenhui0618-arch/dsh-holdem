# 牌桌固定八人：你 + 七位智能体

## 背景

上游的插件是六人桌：1 名人类（seat 0）对 5 位带创始人人设的智能体，桌面座位坐标按座位下标写死。
本 fork 要加雷军（小米）与张一鸣（字节跳动）两位人设。若沿用「六座 + 花名册轮换」，每局都会有一位
角色上不了桌，与「固定」的预期不符。

## 决定

- 牌桌固定 **8 座**：你（seat 0）+ 7 位智能体（Altman、达里奥、马斯克、梁文峰、黄仁勋、雷军、张一鸣）。
- 座位数由 `BOTS` 派生（引擎全程用 `players.length`），不再写死 6。
- 座位环改为按人数计算（`seatAngle` / `seatPos` / `seatIsTop`），椭圆桌坐标对任意人数成立。
- 雷军与张一鸣**不随包分发真人肖像**，默认回落到按 id 生成的 identicon；用户可用既有的
  「上传覆盖」功能换成自己的图。ADR-0003 的五张随包肖像保持不变。

## 后果

- 空桌提示与顶部名单从快照生成，花名册变化不会再让文案过期。
- 每手玩家更多、边池更多，单局手数与时长变长，这是产品预期内的代价。
- 依赖固定 6 座的测试与脚本要改为按 `players.length` 计算（`test/rebuys.test.mjs`、
  `test/avatars.test.mjs` 已更新）。
